# Muse Windows Client（非官方）

一个简单的 Windows 桌面客户端壳子：在桌面窗口里打开 Muse 网页版（https://muse.ai），不用一直开着浏览器标签页。

当前版本：**v0.2.0**（Phase 1 已完成，见下文“v0.2.0 更新内容”）。

## 这是什么 / 不是什么

**是：**

- 一个 Electron 壳子，只做一件事：打开 https://muse.ai
- 登录状态会保存下来，下次打开不用重新登录（和浏览器一样）
- 有系统托盘、快捷键、开机自启动开关、简单的菜单和设置窗口
- 设置会保存在本机，重启后自动恢复（窗口大小 / 位置、缩放、关闭行为、快捷键开关、开机自启动）

**不是：**

- **不是官方 Muse 客户端。** Muse 是 Meta 的产品，官方目前只有 iOS、Android、网页版和 Mac 桌面客户端，没有 Windows 官方客户端。
- 不是重新实现的 Muse，没有改动 Muse 的任何功能。
- 没有 Mac 客户端才有的原生功能，例如全局语音听写、读取 Mac 上的文件 / 短信、系统级集成、设备配对等。哪些功能做不了、为什么做不了，见 `FEATURE_ANALYSIS.md`。
- 不包含任何账号、密码、Token。登录请用你自己的 Muse 账号。

## v0.2.0 更新内容（Phase 1，2026-11-13）

相对 v0.1.0 的改动：

- **修复：开机自启动不再每次启动都被重置。** v0.1.0 有一个 bug：每次启动都把开机自启动强制关掉。现在你的选择会保存在本机配置文件里，下次启动自动恢复。
- **新增：设置持久化。** 窗口大小 / 位置、页面缩放、关闭行为（最小化到托盘 / 直接退出）、快捷键开关、开机自启动、启动时检查更新，都会保存并在下次启动时恢复。设置文件在 `%APPDATA%\Muse Windows Client\config.json`，里面没有任何账号或密码。
- **新增：设置窗口。** 托盘右键菜单 → “设置…” 或菜单“文件 → 设置…” 打开。可以改开机自启动、关闭行为、快捷键开关、启动时检查更新，改完立刻保存。
- **修复：托盘图标。** 现在会按顺序尝试 `.ico` 和 `.png`，哪个能解码用哪个；Windows 上优先用 `.ico`。
- **修复：全局快捷键失败不再悄悄失效。** `Ctrl+Alt+M` 如果被别的软件占用了，会在托盘里弹一次提示，托盘菜单里也会标出“注册失败”，应用本身不会崩溃，仍可用托盘图标显示 / 隐藏窗口。
- **修复：窗口位置恢复。** 上次的窗口大小 / 位置会记住；如果换了显示器、原来的位置已经不在屏幕上，会自动回到主显示器，不会“窗口丢了找不着”。
- **新增：检查更新。** 菜单“帮助 → 检查更新”或托盘菜单“检查更新”可以手动检查；启动后约 8 秒也会静默检查一次。只检查 + 提示，不会静默下载或安装。发现新版本时会问你要不要下载，下载完再问你要不要重启安装。更新需要先配置 GitHub 仓库，见下文“自动更新”。
- **其他：** 单实例（重复双击图标不会再开一个窗口，而是显示已有窗口）；外部链接仍在默认浏览器打开；版本号升到 0.2.0。

## 功能

- 主窗口默认 1280×860，打开 https://muse.ai，登录会话保存在 `persist:muse` 分区；窗口大小 / 位置、缩放会记住
- 外部链接在默认浏览器里打开，不会在应用里乱跳
- 菜单：文件（重新加载、回到首页、设置、退出）、查看（放大 / 缩小 / 恢复大小、开发者工具）、帮助（关于、检查更新、打开 muse.ai）
- 系统托盘：点托盘图标显示 / 隐藏窗口；右键菜单有显示 / 隐藏、重新加载、开机自启动、快捷键开关、关闭时最小化到托盘、设置、检查更新、退出
- 关闭窗口时默认最小化到托盘，不会真的退出；要真正退出请用托盘菜单里的“退出”，或在设置里把关闭行为改成“直接退出”
- 全局快捷键 `Ctrl+Alt+M` 显示 / 隐藏窗口（如果这个快捷键被别的软件占了，注册会失败，应用仍可正常使用，托盘里会提示）
- 开机自启动：默认关闭，在托盘右键菜单或设置窗口里开启，开启后会记住

## 在 Windows 上使用

### 环境要求

- Windows 10 / 11（64 位）
- Node.js 20 或以上 + npm（只在开发 / 打包时需要；直接用打包好的安装包时不需要）

### 方法一：直接用打包好的安装包（推荐）

1. 在 Windows 电脑上打开本项目，运行打包命令（见下文“打包”）。
2. 打包完成后，在 `dist/` 里找到安装包，例如：
   - `Muse Windows Client Setup 0.2.0.exe`（NSIS 安装包）
   - `Muse Windows Client-0.2.0-portable.exe`（便携版，不用安装）
3. 双击安装包安装，或直接运行便携版。
4. 第一次打开会显示 Muse 网页版登录页，用你自己的 Muse 账号登录即可。

> **SmartScreen 警告（正常现象）：** 本项目目前没有代码签名证书，Windows 第一次运行时 SmartScreen 可能会弹警告，说“Windows 已保护你的电脑”。这是因为没有证书，不是病毒。如果你确认这个安装包是你自己（或从你信任的来源）打包的，点“更多信息”→“仍要运行”即可放行。以后如果要正式分发，再考虑买代码签名证书。

### 方法二：开发模式运行

在 Windows 电脑上打开命令行（PowerShell 或 CMD），进入项目目录：

```bat
npm install
npm start
```

窗口打开后就是 Muse 网页版，直接登录使用。

## 打包（在 Windows 电脑上）

```bat
npm install
npm run dist
```

打包完成后，输出在项目下的 `dist/` 目录：

- NSIS 安装包：`dist/Muse Windows Client Setup 0.2.0.exe`
- 便携版：`dist/Muse Windows Client-0.2.0-portable.exe`

只打包便携版：

```bat
npm run build:portable
```

> 注意：NSIS 安装包必须在 Windows 上打包。在 Linux 上打包 NSIS 会失败（缺少 `wine`），便携版在 Linux 上可以打出，但请以 Windows 上打出的为准。

## 自动更新

更新检查用 `electron-updater` + GitHub Releases，只检查 + 提示，**不会静默下载或安装**。

`package.json` 里已经写好了一个占位配置：

```json
"publish": { "provider": "github", "owner": "mingzhen", "repo": "muse-windows-client" }
```

**在配置好之前，检查更新会失败并提示，属正常情况。** 要让它真正工作，需要 mingzhen 做这几步：

1. 在 GitHub 上创建一个仓库，例如 `mingzhen/muse-windows-client`（如果仓库名或账号不一样，改 `package.json` 里 `build.publish` 的 `owner` / `repo`）。
2. 把本项目代码推到这个仓库。
3. 在仓库里发布一个 Release（版本号要比 0.2.0 高，例如 0.3.0），并把打包好的安装包 / 便携版作为 Release 的附件上传（`electron-updater` 靠 Release 附件和 `latest.yml` 找更新）。
4. 在 Windows 上用新版本验证一次“检查更新”能找到新版本。

没有这几步时，应用仍可正常使用，只是“检查更新”会提示失败，不影响其他功能。

## 常见问题

**登录后关掉再打开，又要重新登录？**

- 正常情况下不会。登录会话保存在 `persist:muse` 分区里。
- 如果每次都要重新登录，先确认是不是点了托盘“退出”之外的清理工具清掉了应用数据，或者浏览器隐私设置影响了 Muse 网页版本身。

**页面空白 / 打不开 muse.ai？**

- 先确认 Windows 电脑能正常上网、能打开 https://muse.ai。
- 试试菜单里的“重新加载”，或按 `Ctrl+R`。
- 如果公司 / 学校网络有限制，网页版本身也打不开的话，这个壳子也打不开。

**一打开就显示“出错了”，还没登录？**

- 这是 muse.ai 网页本身加载失败。v0.2.1 起客户端会用桌面版 Chrome 的标识访问，并弹出诊断提示显示真实错误代码。
- 最可能的原因是中国大陆直连 Meta 服务受限：先在同一台电脑的 Edge/Chrome 里打开 https://muse.ai ——如果浏览器里也打不开，就是网络问题，需要 VPN/代理才能用；如果浏览器能打开、客户端打不开，把诊断提示里的错误代码发给 Edison。
- 也可以点诊断提示里的“在浏览器中打开”，先在浏览器里正常使用。

**托盘图标不见了？**

- 应用默认关闭窗口时最小化到托盘，不是退出。点一下任务栏右侧的托盘区（可能在“显示隐藏的图标”箭头里）就能找到。
- 如果找不到，可能是应用已经从托盘退出了，重新双击桌面图标打开即可。

**快捷键 Ctrl+Alt+M 没反应？**

- 这个快捷键可能被别的软件占用了，注册失败时应用仍可正常使用，托盘里会弹一次提示，托盘菜单里也会标出“注册失败”。
- 用托盘图标点一下显示 / 隐藏窗口，或者在设置窗口里先把快捷键关掉再打开（会重新尝试注册）。

**开机自启动怎么关？**

- 右键点托盘图标，把“开机自启动”前面的勾去掉即可；也可以在设置窗口里关掉。改完会记住，下次启动不再自动开。

**设置改了但重启后又变回去了？**

- 设置存在 `%APPDATA%\Muse Windows Client\config.json`。如果这个文件被清理工具删了或损坏了，应用会用默认值启动，不会崩溃。
- 如果每次重启都丢设置，先确认是不是有清理工具在删 `%APPDATA%` 下的文件。

**检查更新一直失败？**

- 先确认有没有按上文“自动更新”配置 GitHub 仓库并发布 Release。没配置时失败是正常的。
- 如果已经配置了还失败，把弹出的错误信息原样发给 Edison。

**怎么换图标？**

- 把你自己的图标替换 `build/icon.ico`（Windows 用）和 `build/icon.png`，重新打包即可。

## 安全说明

- 代码里没有任何账号、密码、Token，也不会把你的登录信息发到任何地方（除了你自己在 muse.ai 登录时发给 Muse 本身）。
- 网页部分以沙箱方式运行，`nodeIntegration: false`、`contextIsolation: true`、`sandbox: true`，预加载脚本不暴露 Node 能力。
- 设置文件只存界面偏好（开机自启动、关闭行为、快捷键开关、缩放、窗口位置、是否启动时检查更新），不存任何账号信息。
- 不做远程电脑控制，不读本地应用的私有数据，不破解任何应用的本地数据库。
