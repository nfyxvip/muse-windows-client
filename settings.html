格式例如 Ctrl+Alt+M、Ctrl+Alt+Q、Ctrl+Shift+K。至少要一个修饰键（Ctrl / Alt / Shift）加一个按键。改完立刻生效。

Quick chat

Quick chat 是一个小聊天窗口，和主窗口用同一个登录状态，不用重新登录。按快捷键弹出，再按一次收起；按 Esc 也可以收起。窗口大小和位置会被记住。

注意：网页版没有精简入口，小窗口里显示的是完整 muse.ai 页面，内容会比较挤。

悬浮按钮

一个可以拖动的小圆按钮，一直置顶显示。点一下显示 / 隐藏主窗口，右键可以打开 Quick chat 或隐藏它。默认关闭，全屏游戏或看视频时建议关掉。

通知

关掉后，muse.ai 网页的消息提醒也不会弹出来。

权限

这三项默认全部关闭，第一次使用时会再弹窗说明、请你确认。

框选区域：

本地操作白名单（只允许这几个，其他程序一律打不开）

本地操作不会远程触发、不会后台静默控制、不会记录键盘鼠标。远端控制 Windows 明确不做。

本地模型

连接你自己的模型（llama.cpp / Ollama / LM Studio），走 OpenAI 兼容接口。一次只启用一个；启用的模型会出现在“本地模型”聊天窗口里。muse.ai 仍然走 Meta 的云端。

任务执行器

执行 Edison 在聊天里给的命令清单（任务包）。只在授权文件夹里、只跑白名单里的命令，每次执行前都会把全部步骤列出来问你一次；报告由你自己复制回聊天。

快捷键：
白名单：

白名单一行一个程序名（只能是程序名，不能带路径或符号）。默认：php、composer、git、npm、node、npx。任务包里出现白名单外的命令，整包会被拒绝。改完点别处就保存。

文件与授权文件夹

壳子只会读取下面授权文件夹里的文件。拖文件进聊天、或用“发送文件到聊天”时，壳子会先核对：不在授权列表里的文件一律拒绝；黑名单里的文件夹即使在授权列表里也拒绝。授权之前，壳子什么文件都不读。
